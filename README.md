# Render Deployment Practice 🚀

## About This Repository

This repository was created to practice deploying a Node.js and Express.js backend application on Render.

## What I Practiced

* Creating a Node.js project
* Initializing NPM using `npm init -y`
* Installing Express.js
* Creating a basic Express server
* Using environment variables
* Preparing the project for deployment
* Deploying the backend application on Render

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

## Run the Project

Start the server using:

```bash 
node index.js
```

## Technologies Used

* Node.js
* Express.js
* NPM
* Render

## Purpose

The main purpose of this repository is to understand the backend deployment process and practice deploying Node.js applications using Render.

## Learning

This is a practice project created while learning Backend Development.
